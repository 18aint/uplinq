# Veo 3 Prompt - Website Audit Tool LinkedIn Video

## 🎬 **Master Prompt for Veo 3**

```
Create a 90-second vertical (9:16 aspect ratio) promotional video with dynamic zoom animations revealing hidden website problems and introducing a solution.

VISUAL STYLE: Clean, modern, tech-focused with smooth camera movements. Professional blue color scheme (#2D72F9) with red warning elements. High contrast, crisp typography.

SEQUENCE:

[0-5 seconds] OPENING HOOK
Start with extreme close-up of a beautiful, modern website homepage. Slowly zoom out to reveal the full page looking pristine and professional. Suddenly, subtle glitch effects appear - pixels flickering, slight distortions. Text overlay appears: "Your website looks perfect... but what's hiding underneath?"

[5-20 seconds] SEO PROBLEMS REVEALED
Camera smoothly zooms into the website's HTML code layer, diving deep into the <head> section. Missing meta description tags highlight in pulsing red. Multiple H1 tags multiply on screen showing errors. Images appear without alt text, marked with red X symbols. Text overlay: "Hidden SEO Issues Killing Your Rankings" with animated counter: "73% of websites have critical SEO problems"

[20-35 seconds] PERFORMANCE ANALYSIS
Zoom into a loading spinner that spins slowly and frustratingly. Transform to PageSpeed Insights interface showing poor scores in red. Large image files appear with file size warnings floating above them. Compression meters show "NOT OPTIMIZED" in red. Text overlay: "Speed Issues Driving Customers Away" with counter: "Every 1 second delay = 7% fewer conversions"

[35-50 seconds] MOBILE EXPERIENCE PROBLEMS
Camera zooms out to show website displayed on a mobile device mockup. Text appears too small to read - magnifying glass effect highlights the tiny text. Finger attempts to tap buttons that are too close together, missing targets. Website doesn't fit screen properly, requiring horizontal scrolling. Text overlay: "Mobile Problems You Can't See" with counter: "54% of traffic is mobile"

[50-65 seconds] SECURITY VULNERABILITIES
Zoom into browser address bar showing HTTP instead of HTTPS. Security warning icons appear with red locks and shield symbols marked with X. Data visualization shows information "leaking" from the website with particle effects. Text overlay: "Security Holes Putting You at Risk" with counter: "43% of cyber attacks target small businesses"

[65-85 seconds] SOLUTION REVEAL
Camera zooms out dramatically to reveal a clean, professional website audit tool interface. All the previous red X marks transform into green checkmarks with satisfying animation. Score counter rapidly improves from 45 to 89. Progress bars fill to 100% with smooth animations. Text overlay: "Get Your FREE Website Audit in 2 Minutes"

[85-90 seconds] CALL TO ACTION
Final zoom into the URL "uplinq.digital/website-audit" with typing animation effect. Mouse cursor clicks "Start Free Audit" button. Quick montage of different websites being audited. End with Uplinq logo animation and branded blue background.

CAMERA MOVEMENT: Smooth, cinematic zoom ins and outs. No shaky movements. Professional documentary style.

TYPOGRAPHY: Bold, sans-serif fonts. White text on dark overlays. Red for problems, green for solutions, blue for branding.

AUDIO: Upbeat electronic music building in intensity. Sound effects for warnings, success chimes for solutions.

MOOD: Starts mysterious/concerning, builds tension through problems, resolves with optimistic solution reveal.
```

## 🛠 **Veo 3 Optimization Tips**

### **To Get Better Results:**

1. **Break into multiple prompts** if Veo 3 struggles with the full sequence
2. **Start with individual scenes** then combine in editing
3. **Use specific camera terms** like "dolly zoom," "rack focus," "crane shot"
4. **Include reference styles** like "Apple commercial style" or "tech startup promo"
5. **Specify frame rates** and motion blur preferences
